# Browser State and Localisation Component

This component is **not applicable** to Android Debloater. The script is a host-side Bash automation tool with no browser, web UI, or localisation concerns.

## Rationale

- No web interface or browser-based interaction
- No internationalisation or localisation support
- No persistent browser state or cookies
- Console output is English-only with ANSI colour codes

This file exists to document the explicit absence of this concern in the architecture.
